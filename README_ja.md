R-Instatは、Rを基盤とした無料のメニュー駆動型統計ソフトウェアです。このソフトは、R統計システムの強力な機能を活用しつつ、メニューやダイアログベースのインターフェースによって、他の従来のポイント＆クリック型統計ソフトウェアと同様に使いやすく設計されています。

## ダウンロード

最新版はhttps://r-instat.org/からダウンロードでき、そちらにはインストール手順や初心者向けガイドも掲載されています。R-Instatは現在、Windows専用のソフトウェアです。必要なRパッケージを含むすべての前提条件がインストールファイルに含まれています。

## 背景

### アフリカン・データ・イニシアティブ

R-Instatは、アフリカ全土における統計処理能力とデータリテラシーの向上を支援することを目的とした協力プロジェクトである[アフリカン・データ・イニシアチブ](http://africadata.org/)（ADI）のもとで開発された最初の製品です。アフリカン・データ・イニシアチブの全体的な目標はこのソフトウェアの制作にとどまらないものですが、私たちはR-Instatが変革を実現するための重要な第一歩だと考えています。

R-Instatの当初のターゲットユーザー層については、その開発を開始した[クラウドファンディングキャンペーン](https://chuffed.org/project/africadatainitiative)で説明されています。そこでは、利用可能な統計ソフトウェアに不足があり、使いやすく、無料でオープンソースであり、適切な統計手法の採用を促す統計ソフトウェアが求められていると述べました。詳細については、私たちの3分間のキャンペーン動画をご覧ください：

[![African Data Initiativeキャンペーン動画](http://img.youtube.com/vi/0_YAjLBVPrI/0.jpg)](http://www.youtube.com/watch?v=0_YAjLBVPrI)

### R

R-Instatは、[R統計システム](https://www.r-project.org/)へのインターフェースと見なすことができます。使用するRパッケージについては慎重に検討しましたが、R-Instatの機能を実現するために時として「標準的な」Rコードから逸脱せざるを得ない場合もありました。パッケージ名を含むRコードは、R-Instatのログウィンドウで確認できます。また、R-Instatのグラフィックダイアログで使用されている[ggplot2](http://ggplot2.org/)パッケージの構文を学ぶなど、この機能はRユーザーにとっても役立つかもしれません。Rスクリプトの管理や作成に移行したいユーザーのために、ログファイルをRStudioのスクリプトウィンドウで簡単に開けるようにしています。

### Instat

“R-Instat”に含まれる“Instat”とは、1970年代に初めて開発された[ソフトウェア](https://www.reading.ac.uk/ssc/resourcepage/instat.php)のことで、R-Instatと同様の目的や対象ユーザーを持っています。R-Instatの考え方の多くはInstatから着想を得ています。Instatには気候データ分析用の特別なメニューが搭載されており、R-Instatもこの伝統を受け継ぎつつ、公共調達データ分析用の別の特別メニューも備えています。Instatのユーザーであれば、R-Instatのインターフェースに親しみを感じるはずです。
